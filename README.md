# Sillon

La fiabilité réelle de ton train, pas la moyenne du réseau.

Tu choisis un trajet et un départ, Sillon te montre sur les 90 derniers jours
si ce train précis est arrivé à l'heure, en retard ou pas du tout, et lequel
des départs voisins est le plus fiable.

Les données viennent des fichiers « Ist-Daten » publiés chaque jour par
[opentransportdata.swiss](https://opentransportdata.swiss). Un job nocturne les
agrège, le site est statique, il n'y a pas de serveur.
